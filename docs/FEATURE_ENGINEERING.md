# MediTrack Feature Engineering Specification

## 1. Feature Philosophy & Timing Guarantee
All features are constructed strictly using historical observations available at or before the prediction cutoff date T (t <= T). Under no circumstances is any future data (t > T) or target label information used in feature calculation.

## 2. Feature Mapping & Definitions

| Feature Name | Meaning | Calculation | Available at T? | Future Leakage? |
|---|---|---|---|---|
| current_stock | Current inventory level at cutoff date T | Stock_T | Yes | None |
| stock_change_7d | Net inventory delta over the past 7 days | Stock_T - Stock_{T-7} | Yes | None |
| stock_min_14d | Minimum stock level observed over past 14 days | min(Stock_{T-13:T}) | Yes | None |
| stock_max_14d | Maximum stock level observed over past 14 days | max(Stock_{T-13:T}) | Yes | None |
| stock_std_14d | Standard deviation of stock over past 14 days | std(Stock_{T-13:T}) | Yes | None |
| consumption_7d_mean | Average daily consumption over past 7 days | mean(Consumption_{T-6:T}) | Yes | None |
| consumption_14d_mean | Average daily consumption over past 14 days | mean(Consumption_{T-13:T}) | Yes | None |
| consumption_30d_mean | Average daily consumption over past 30 days | mean(Consumption_{T-29:T}) | Yes | None |
| consumption_7d_std | Variability of daily consumption over past 7 days | std(Consumption_{T-6:T}) | Yes | None |
| consumption_velocity | Short-term to medium-term consumption trend ratio | consumption_7d_mean / (consumption_30d_mean + 1e-5) | Yes | None |
| days_since_last_replenishment | Elapsed days since the most recent stock intake | T - last_replenishment_date | Yes | None |
| last_replenishment_qty | Units received in the most recent stock intake | Replenishment_{last} | Yes | None |
| estimated_days_of_stock | Operational inventory runout estimate (non-ML metric) | Stock_T / (consumption_7d_mean + 1e-5) | Yes | None |
| consumption_to_stock_ratio | Ratio of recent daily demand to current inventory | consumption_7d_mean / (Stock_T + 1e-5) | Yes | None |

## 3. Clear Distinction: Operational Metric vs ML Prediction
- Estimated Days of Stock Remaining: A deterministic inventory arithmetic ratio (Current Stock / Recent Daily Demand). It assumes static, linear future consumption and zero future variability.
- ML Stock-Out Risk Probability: A probabilistic prediction generated by the trained machine learning model that captures nonlinear interactions, volatility spikes, demand surges, and historical replenishment intervals.
